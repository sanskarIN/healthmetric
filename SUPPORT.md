# HealthMetric Support

## Before asking for help

1. Read [`README.md`](README.md).
2. Follow [`docs/setup.md`](docs/setup.md).
3. Check [`docs/troubleshooting.md`](docs/troubleshooting.md).
4. Search existing GitHub issues before opening a new one.

## Privacy when requesting support

Do not send real health records, names, addresses, account credentials, API keys, signing keys, or other sensitive information. Reproduce bugs with fictional/example measurements whenever possible.

## What support can cover

- repository setup;
- build/test/lint failures;
- reproducible application defects;
- accessibility issues;
- documentation questions;
- contribution guidance.

HealthMetric is educational software and does not provide medical diagnosis or personalized medical advice.
